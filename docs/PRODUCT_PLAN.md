# 별빛마을 모험대 — 제품 기획

## 1. 제품 정의

`별빛마을 모험대`는 2021·2022년생 아이들이 각자의 iPad mini로 즐기는 캐릭터 중심 2D 마을 모험 게임이다.

연령 숫자만 보고 단순한 원인·결과 놀이로 제한하지 않는다. 아이들이 이미 요리·제작 앱, 캐릭터 액션 게임, 생활형 마을 게임을 경험한다는 사실을 제품 난도의 기준으로 삼는다.

> 쉽게 시작하지만 탐험하고, 모으고, 만들고, 해금할 것이 계속 생기는 게임

## 2. 중심 재미

1. 좋아하는 캐릭터를 직접 움직인다.
2. 작은 마을을 돌아다니며 주민과 장소를 발견한다.
3. 재료와 도구를 모은다.
4. 피자 만들기, 동물 치료, 건설 같은 촉각적인 활동을 한다.
5. 의상, 가구, 새로운 장소와 능력을 보상으로 얻는다.
6. 자기 공간과 마을이 조금씩 달라지는 모습을 확인한다.

직업 체험은 서로 분리된 유아용 놀이판이 아니라 하나의 마을 안에서 만나는 활동으로 설계한다.

## 3. 디자인 원칙

- 첫 이동은 설명 없이도 30초 안에 이해할 수 있어야 한다.
- 읽지 못해도 아이콘, 표정, 움직임, 소리로 다음 행동을 찾을 수 있어야 한다.
- 실패로 중단시키기보다 다시 시도할 수 있는 반응을 제공한다.
- 미션에는 시작, 과정, 완성, 보상이 모두 있어야 한다.
- 반복할 때 재료, 손님, 보상 중 적어도 하나가 달라져야 한다.
- 화면 가운데에는 손으로 눌러야 하는 고정 버튼을 두지 않는다.
- 이동은 왼쪽 아래, 행동은 오른쪽 아래에 배치한다.
- 가로형 iPad mini를 기준으로 하고 여러 세대의 화면비에 대응한다.
- 전체 장면용 콘셉트 이미지와 실제 게임 화면을 분리하지 않는다. 실제 게임에 들어가는 자산으로만 시안을 평가한다.

## 4. 게임 구조

### 마을 허브

- 광장, 피자가게, 집, 숲길에서 시작한다.
- 이후 동물병원, 공사장, 소방서, 병원 구역이 열린다.
- 건물은 메뉴 버튼이 아니라 캐릭터가 직접 걸어 들어가는 장소다.

### 활동

- 피자가게: 재료 수집, 반죽, 토핑, 굽기, 배달
- 동물병원: 상태 관찰, 검사 도구 선택, 치료, 돌보기
- 공사장: 재료 운반, 길 만들기, 장비 조작
- 소방서: 장비 준비, 이동, 구조와 진화
- 병원: 환자 관찰, 검사, 치료와 회복

### 진행

- 활동을 끝내면 별조각과 꾸미기 보상을 얻는다.
- 별조각으로 새로운 길과 건물을 연다.
- 의상과 가구는 성능 경쟁이 아니라 수집과 표현을 위한 보상이다.

## 5. 기술 방향

- Phaser 기반 HTML5 Canvas/WebGL 2D 게임
- Vite 빌드와 GitHub Pages 배포
- iPad Safari와 홈 화면 웹 앱 지원
- 기기별 진행 상황은 우선 브라우저에 저장
- 실시간 멀티플레이와 계정 시스템은 초기 범위에서 제외
- 조작, 애니메이션, 충돌, 카메라, 장면 전환을 게임 엔진에서 일관되게 관리

## 6. 첫 번째 플레이 빌드

### 범위

- 캐릭터 3종 선택
- 8방향 이동과 걷기 애니메이션
- 터치 조이스틱과 상황별 행동 버튼
- 카메라 추적과 월드 충돌
- 마을 광장 탐험
- 피자가게 발견, 입장, 퇴장
- 기기별 캐릭터 선택 저장
- GitHub Pages 자동 배포

### 완료 기준

- 아이가 설명 없이 이동을 시작한다.
- 화면 가운데를 누르지 않고 양손으로 편하게 조작한다.
- 피자가게 표시를 보고 직접 찾아간다.
- 가까이 갔을 때 행동 버튼의 변화를 알아차린다.
- 피자가게 안으로 들어갔다가 다시 나올 수 있다.
- Safari를 닫았다 열어도 선택한 캐릭터가 유지된다.

## 7. 두 번째 플레이 빌드

첫 완전한 미션을 구현한다.

```text
주민의 부탁
→ 토마토·치즈·밀가루 찾기
→ 반죽·소스·토핑·굽기
→ 주민에게 배달
→ 가구 또는 의상 보상
```

이 미션을 두 아이가 혼자 완료할 수 있는지 검증하기 전에는 다른 직업 건물을 추가하지 않는다.

## 8. 아이 테스트 관찰 항목

- 30초 안에 이동 방법을 이해하는가
- 글을 읽지 않고 피자가게를 찾는가
- 조이스틱과 행동 버튼의 위치가 편한가
- 이동 자체가 답답하거나 미끄럽지 않은가
- 캐릭터와 마을에 관심을 보이는가
- 다시 들어가 보거나 다른 곳을 탐색하려 하는가

말로 정답을 설명하지 않고 행동을 관찰한다. 이해하지 못한 부분은 그래픽을 추가하기 전에 조작, 배치, 피드백부터 수정한다.
