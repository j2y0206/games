# 신규 기획 — 꼬마 일터

## 1. 제품 정의

`꼬마 일터`는 2021·2022년생 아이가 iPad를 가로로 들고, 설명을 듣거나 글자를 읽지 않아도 직업 도구를 직접 만져 보는 웹 역할놀이 시리즈다.

게임의 중심은 점수나 성공 판정이 아니라 다음 경험이다.

> 내가 도구를 잡고 움직이면, 세상이 즉시 자연스럽게 반응한다.

### 대상

- 2021년생과 2022년생, 현재 약 3~5세
- 한 손가락 드래그와 탭은 가능하지만 복잡한 규칙과 글 읽기는 요구하지 않음
- 자동차, 중장비, 물, 동물, 음식 만들기처럼 결과가 눈에 보이는 놀이를 선호한다는 가설에서 시작
- 두 아이가 각자의 iPad로 따로 플레이해도 완전한 경험이 되도록 설계

## 2. 절대 원칙

1. 첫 화면에서 10초 안에 만질 물건을 알 수 있어야 한다.
2. 화면 속 물건을 직접 잡는다. 별도의 조이스틱과 작은 버튼을 만들지 않는다.
3. 한 화면에는 중심 행동을 하나만 둔다.
4. 틀림, 실패, 시간제한, 점수, 별 개수, 광고, 결제를 넣지 않는다.
5. 작업 순서를 강요하지 않는다. 자연스러운 반응으로 다음 행동을 유도한다.
6. 글과 음성 설명이 없어도 놀이가 가능해야 한다.
7. 모든 터치 대상은 최소 72 CSS 픽셀 이상으로 만든다.
8. 아이가 손을 놓으면 도구는 안전한 원래 자리로 돌아온다.
9. 완성 후에는 축하 화면에 갇히지 않고 바로 같은 놀이를 반복할 수 있다.
10. 실제 구현할 수 없는 콘셉트 이미지를 기준으로 삼지 않는다.

## 3. 시리즈 구조

처음부터 여러 직업을 한꺼번에 만들지 않는다. 한 가지 장면을 아이에게 검증한 뒤 같은 조작 문법으로 확장한다.

| 순서 | 일터 | 중심 역할놀이 | 대표 직접 조작 |
|---|---|---|---|
| 1 | 공사장 | 중장비 기사 | 굴착기 바가지를 잡아 모래를 퍼서 덤프트럭에 싣기 |
| 2 | 소방서 | 소방관 | 호스를 잡아 불에 물을 뿌리고 사다리를 움직이기 |
| 3 | 자동차 정비소 | 정비사·세차원 | 호스와 스펀지로 씻고 큰 바퀴를 갈기 |
| 4 | 동물병원 | 수의사 | 붕대 감기, 털 빗기, 간식 주기 |
| 5 | 피자가게 | 요리사 | 반죽 누르기, 소스 바르기, 재료 올리기 |
| 6 | 병원 | 의사 | 청진기 대기, 체온 재기, 반창고 붙이기 |

메인 화면은 최소 두 개의 일터가 완성된 뒤 만든다. 그전에는 검증할 장면으로 바로 진입한다.

## 4. 첫 검증 콘텐츠 — 공사장 모래 싣기

### 선택 이유

- 굴착기와 덤프트럭은 기능과 움직임의 관계가 명확하다.
- 퍼기, 옮기기, 쏟기라는 손동작이 한 손가락 드래그와 잘 맞는다.
- 모래의 양과 위치가 변해 결과를 즉시 이해할 수 있다.
- 같은 행동을 여러 번 반복해도 역할놀이로 자연스럽다.

### 첫 화면

- 왼쪽: 크고 부드러운 모래더미
- 가운데: 노란 굴착기와 크게 보이는 바가지
- 오른쪽: 빈 적재함이 보이는 덤프트럭
- 배경: 단순한 울타리, 하늘, 땅. 움직이지 않는 장식은 최소화
- 글자, 화살표, 손가락 그림, 시작 버튼 없음

### 놀이 흐름

1. 굴착기 바가지가 아주 작게 한 번 움직여 만질 수 있음을 보여 준다.
2. 아이가 바가지를 손가락으로 잡아 모래더미에 넣으면 모래가 담긴다.
3. 담긴 바가지를 트럭 적재함 위로 옮기면 모래가 실제로 떨어진다.
4. 트럭이 무게를 받아 살짝 내려앉고 만족스러운 소리가 난다.
5. 세 번 정도 실으면 트럭이 경적을 울리고 천천히 나간다.
6. 곧 빈 트럭이 다시 들어오며 놀이가 계속된다.

정확히 세 번을 채우지 못해도 실패하지 않는다. 모래를 바닥에 쏟으면 작은 모래더미가 생기고 다시 퍼 올릴 수 있다.

### 보조 반응

- 굴착기 몸체를 탭하면 작업등이 켜진다.
- 덤프트럭 운전석을 탭하면 짧은 경적이 난다.
- 바퀴를 문지르면 조금 회전하지만 중심 놀이를 방해하지 않는다.
- 5초 동안 아무 입력이 없을 때만 바가지가 한 번 부드럽게 움직인다.

## 5. 화면과 그래픽 기준

- iPad 가로 화면 우선, 4:3과 16:9 모두 대응
- 단순한 2D 만화풍 SVG와 CSS 사용
- 외곽선 굵기와 그림자 방향을 모든 물체에서 통일
- 사진 같은 재질, 복잡한 광택, 전체 장면 AI 이미지는 사용하지 않음
- 배경과 움직이는 물체를 처음부터 분리된 요소로 제작
- 움직임은 짧고 무게감 있게 만들며 과도한 반짝임과 폭발 효과는 피함
- 노란 중장비, 파란 하늘, 따뜻한 흙색처럼 물체별 색 구분을 명확하게 함

## 6. 소리 기준

- 첫 터치 이후에만 소리를 재생한다.
- 기계음은 크거나 날카롭지 않게 짧게 사용한다.
- 행동마다 서로 다른 소리를 준다: 모래 퍼기, 모래 떨어짐, 경적, 엔진.
- 배경음악은 첫 검증판에 넣지 않는다.
- 보호자가 쉽게 끌 수 있는 큰 음소거 버튼 하나만 둔다.

## 7. 기술 기준

- 설치 없는 HTML, CSS, JavaScript 웹 게임
- 움직이는 물체는 각각 독립된 SVG 또는 DOM 요소
- 한 손가락 Pointer Events만으로 모든 중심 행동 수행
- 외부 CDN, 로그인, 인터넷 연결 없이 가정 LAN에서 실행
- 브라우저 스크롤, 확대, 길게 누르기 메뉴 방지
- 프레임 저하를 막기 위해 화면에 동시에 존재하는 장식 애니메이션 제한
- 저장이 필요해질 때까지 서버 데이터베이스를 사용하지 않음

## 8. 첫 아이 테스트의 성공 기준

어른은 “한번 해봐” 이외의 설명을 하지 않는다.

- 10초 안에 굴착기 바가지를 만진다.
- 60초 안에 모래를 한 번 이상 트럭에 넣는다.
- 손을 놓거나 엉뚱한 곳에 끌어도 화면이 망가지지 않는다.
- 같은 행동을 자발적으로 두 번 이상 반복한다.
- 아이가 다음에 무엇을 해야 할지 묻지 않는다.

두 아이 중 한 명이라도 중심 행동을 이해하지 못하면 그래픽을 고급화하지 않고 조작과 배치부터 수정한다.

## 9. 제작 단계

1. 정적 화면 배치: 모래더미, 굴착기, 트럭의 크기와 위치만 검증
2. 회색 기능판: 바가지 드래그, 모래 담기, 쏟기만 구현
3. 데스크톱 마우스와 iPad 터치 검증
4. 이해가 확인된 뒤 최종 만화풍 SVG 적용
5. 소리와 짧은 반응 애니메이션 추가
6. 두 아이의 무설명 플레이 관찰
7. 통과 후에만 다음 일터 제작

## 10. 이번 단계에서 만들지 않는 것

- 여러 직업을 고르는 메인 마을
- 캐릭터 꾸미기와 보상 수집
- 미션 목록과 진행률
- 순위, 계정, 이름 입력
- 온라인 멀티플레이
- 완성 화면처럼 보이기 위한 배경 이미지

이 요소들은 첫 장면의 직접 조작이 아이에게 통한다는 사실을 확인한 뒤 다시 판단한다.
